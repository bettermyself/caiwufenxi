## 三、逐项核查

### 1. 现金及现金等价物勾稽核对 ✅

现金流量表四项加总（P66）：

```
期初 169,970,089,257.83
+ 经营净额  +61,522,204,989.35
− 投资净额  −31,641,898,948.89
− 筹资净额  −73,427,081,208.87
+ 汇率影响  +2,295,358.30
= 期末 126,425,609,447.72   ← 与现金流量表期末余额完全一致
```

与资产负债表的桥接（余额口径）：

```
货币资金 516.91 + 拆出资金 991.21(余额) + 买入返售 88.80 = 1,596.91 亿
− 受限货币资金 72.54（存放央行法定存款准备金，附注27 P102）
− 受限拆出资金 233.16（不能随时支取的同业存款，附注27，余额口径）
− 残差 26.95（倒挤：1,596.91 − 72.54 − 233.16 − 1,264.26；
  未受限但不符合现金等价物"3个月内"定义，构成见下表）
= 1,264.26 亿 ← 现金及现金等价物，与附注61(4)构成表完全一致
```

附注61(4)（P116）构成自验：库存现金 0.001 + 可随时支付银行存款 431.13 + 可随时支付其他货币资金 0.14 + 可用于支付存放央行款项 7.28 + 存放同业 740.97 = 现金 1,179.53；+ 买入返售（现金等价物）84.73 = 1,264.26 ✓。**勾稽精确成立**，残差占比仅 1.7%。

残差 26.95 亿元的构成（年报未直接披露该数，系倒挤值；四块均可从披露独立验证，合计精确闭合）：

| 构成 | 金额（亿） | 推导依据 |
|---|---|---|
| 拆放同业（期限超3个月） | 12.00 | 附注2拆出资金明细"拆出资金"行；附注61(4)"拆放同业款项"行为空白 → 整块未计入现金 |
| 3个月以上买入返售 | 4.07 | 资产负债表买入返售 88.80 − 附注61(4)计入现金等价物的 84.73 |
| 定期/通知类银行存款 | 5.81 | 银行存款 517.68 − 可随时支付 431.13 − 央行可用 7.28 − 法定准备金（受限）72.54 |
| 长期限存放同业 | 5.07 | 存放同业 979.20 − 计入现金 740.97 − 受限 233.16 |

注1：第3、4块的拆分取决于央行超额准备金（7.28亿）归位于"货币资金—银行存款"还是"拆出资金"，两种读法下定期类存款在 5.8~13.1 亿、同业类在 17.1~9.8 亿之间移动，四块合计恒为 26.95 亿。注2：若全用账面价值口径（拆出资金 991.0、受限 233.10），残差为 26.76 亿，差 0.18 亿为未受限拆出资产的减值准备。

### 2. 财务公司「拆出资金」口径 ✅

茅台持有贵州茅台集团财务有限公司 51% 股权并纳入合并（P120）。清单要求：现金及现金等价物 = 货币资金 + 拆出资金中不受限资金之和。本次核对已采用该口径（见上项），成立。拆出资金构成（附注2 P84）：存放同业款项 979.20 + 拆出资金 12.00 − 减值准备 0.24 = 991.0（账面价值）。

### 3. 货币资金来源鉴别 ✅

- 经营活动现金流量净额 **+615.22 亿**（P65），连续为正且远大于资本开支；
- 筹资流入为零（无借款、无增发），筹资流出 734.27 亿全部为分红 672.42 亿 + 回购等 61.85 亿；
- 现金及等价物本年减少 435.44 亿，全部由「分红+回购（734 亿）> 经营净流入（615 亿）+ 财务公司存单配置净增」解释。
- **结论：全部为经营积累，无变卖资产、无举债凑现金。**

### 4. 与短期债务、经营需要的匹配 ✅

有息负债仅租赁相关两项合计 **2.34 亿**（一年内到期非流动负债 0.44 + 租赁负债 1.90），无任何借款和债券。

- 现金债务比（清单 8.1 保守口径）= 现金及现金等价物 1,264.26 亿 ÷ 有息负债 2.34 亿 ≈ **541 倍**（标准 ≥1）；
- 即便把财务公司吸收存款 180.38 亿（付息 0.35%–1.70%）也视作刚性付息负债，覆盖率仍达 **6.9 倍**；
- 「过大」一端的问题归入第 11 项货币冗余讨论。

### 5–8. 四类反常信号 ✅ 均排除

- **货币资金远小于短期负债**：不存在，方向完全相反。
- **存贷双高**：不存在。货币资金+拆出资金 1,508 亿 vs 有息负债 2.34 亿；财务费用利息费用仅 0.29 亿（其中租赁利息 0.09 亿，附注50 P109）。吸收存款是财务公司对集团成员的经营性负债（金融牌照业务），不是集团自身高息举债。
- **定期/其他货币资金巨大却缺流动资金**：不存在。可随时用于支付的银行存款 431.13 亿，流动性极充裕；银行存款中不可随时支取部分 85.6 亿里 72.5 亿为法定准备金（金融监管常规），其余约 5.8~13.1 亿为 3 个月以上定期/通知类存款。
- **其他货币资金无解释**：不存在。其他货币资金仅 1,445 万元（占货币资金 0.028%），无大额票据保证金、意向金异常。

### 9. 利息收入与存款利率匹配 ✅

全口径利息收入 = 利润表利息收入（财务公司经营收入，附注45）32.16 亿 + 财务费用—利息收入（附注50）8.43 亿 = **40.59 亿**。
平均生息基数（货币资金+拆出资金期初期末平均）= 1,686.35 亿；加回买入返售平均 80.50 亿 = 1,766.85 亿。

- 综合收益率 = 40.59 ÷ 1,686.35 ≈ **2.41%**（含买入返售口径 2.30%）；
- 参照系：2025 年商业银行一年期定存挂牌利率约 1% 上下，同业存单收益率约 1.6%–1.9%；茅台收益率高于市场基准（含 3.65% 关联贷款及存量较高利率存单贡献）；
- 自有资金口径单独验证：财务费用利息收入 8.43 亿 ÷ 平均货币资金 554.9 亿 ≈ 1.52%，符合协定/通知存款水平。
- **结论：无「资金只在报表日短暂停留」迹象。**（对照：上期财务费用利息收入 14.77 亿 ÷ 上期平均基数更高——利率下行期的正常降幅。）

### 10. 控股股东资金池归集 ✅ 不存在（方向相反）

清单警示的是控股股东通过「集团资金管理协议」归集上市公司资金。茅台的实际情况相反：

- 集团成员单位（含集团公司期末存款 83.31 亿）把钱**存入上市公司控股 51% 并合并报表的财务公司**（吸收存款 180.38 亿，附注30 P103），存贷均有关联交易专项披露（P42-44：存入 1,428.66 亿/取出 1,479.30 亿，利率 0.35%–1.70%）；
- 财务公司资产端为存放央行、同业存放、同业存单等高流动性低风险资产；
- 上市公司报表层面无「存放财务公司存款」受限或被归集的披露，无资金管理协议归集情形。
- 需要留意的仅有：合并-母公司货币资金差额 339.96 亿（母公司 856.87 > 合并 516.91，见第 5.3 条），系母公司存放财务公司存款在合并中抵销重分类所致——资金位于上市公司体系内部，不属于被集团占用。

### 11. 货币冗余 ⚠️ 存在（中性偏负面，估值扣分项）

- 期末现金及现金等价物 1,264.26 亿，另有债权类投资约 314.8 亿（一年内到期债权投资 268.71 + 债权投资 11.13 + 其他债权投资 34.97），类现金合计约 **1,579 亿**，占总资产 52%、占净资产 62%；
- 本年现金需求：资本开支（购建长期资产支付现金，P64）31.28 亿 + 分红 672.42 亿 + 回购等其他筹资流出 61.85 亿 = 765.55 亿；
- **现金及等价物 ≈ 1.65 年的「资本开支+全额分红」需求**；且 2026 年度分红已预案每股 27.993 元（约 350 亿，P1），仍可轻松覆盖；
- 按《手把手》口径属于典型货币冗余：约 2.3%–2.4% 的现金收益率显著低于公司 ROE（本期约 34%），拖累整体资金使用效率——这是茅台长期已知的估值折价因素（大量低收益现金躺在账上），不是安全问题。

### 13. 定期存款与现金等价物认定 ✅

- 现金等价物仅认定买入返售金融资产 84.73 亿（附注61(4)），资产负债表买入返售 88.80 亿中 4.07 亿（超过 3 个月或受限部分）未计入，从严处理正确；
- 银行存款中约 5.8~13.1 亿为 3 个月以上定期/通知类存款，连同拆放同业 12.0 亿、3 个月以上买入返售 4.1 亿（合计即三.1 残差 26.95 亿）：未受限（不属于附注27），但按「3 个月内易于转换」标准不计入现金及现金等价物——处理符合准则；
- 法定准备金 72.5 亿剔除、超额准备金（可用于支付的存放央行款项 7.28 亿）计入，与清单第 13 条的口径要求一致；
- 附注61(5)「使用范围受限但仍作为现金及现金等价物列示」勾选「不适用」，无隐藏条款；
- 无大额承兑汇票/信用证保证金问题（其他货币资金仅 1,445 万）。

## 五、提示事项（不影响安全性结论）

1. **货币冗余**是唯一实质发现：约 1,579 亿类现金（占总资产 52%）收益率仅 2.3%–2.4%，远低于公司资本回报水平，估值时应将这部分现金按低倍数或直接剔除处理。
2. **披露口径小差异**：附注27 受限货币资金 7,254,499,309.26 vs 附注61(6) 法定存款准备金 7,250,789,537.15，相差 3,709,772.11 元（371 万），原文如此，金额不重大；类似地关联利息支出 175,774,971.68 与利润表利息支出 175,775,959.12 相差 987.44 元。属四舍五入/统计口径差异，非异常。
3. **财务公司集中度**：类现金的约 60% 由财务公司以同业存放/同业存单/买入返售形式运作（其中 233 亿为不可随时支取的长期限同业存款），本质是信用风险极低的金融资产，但意味着集团现金对银行间市场利率下行敏感——2025 年利息收入已随利率下行小幅回落（40.6 亿 vs 上期 47.2 亿）。
